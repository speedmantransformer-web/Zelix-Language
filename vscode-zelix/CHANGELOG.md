# Changelog

## 0.3.0

- Added an interpreter-backed Zelix debugger with breakpoints, stepping, stack frames, local variables, and output.
- Added **Zelix: Debug Current File** and F5 launch configurations, retaining the Zelix Marketplace logo.
- Documented debugger setup and the current interactive-input limitation.

## 0.2.0

- Added project initialization and local package installation commands.
- Added automatic use of the installed Zelix CLI, with source-checkout and custom-script support.
- Expanded extension documentation for project/package workflows.
- Set the Marketplace publisher to `CloudZ`.
